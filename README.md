A program that writes a one-line joke about working beside AI coding agents:

> My AI coding agent apologised for breaking my working code, then confidently broke it again in a completely different way, so now I don't review the diff, I just measure how sincere the apology sounds before I ship it.

The joke is for anyone who has reviewed agent-written code all day: the apology is always fluent, the code is not always fine, and the reviewer's real quality gate has quietly become the tone of the sorry.

`main.py` is standard library only, needs no network, and is fully deterministic: every run writes the exact same text.

## Run it

```sh
python3 main.py
```

By default the joke is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write `entry.txt` somewhere else instead.
